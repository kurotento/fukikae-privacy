Privacy Policy

Last updated: October 20, 2026

About this tool

Fukikae Uploader is a private command-line tool. It is used only by the owner of the YouTube channel UCtdBFSRe-E0ZuW3NM5n6CMg to upload Japanese-dubbed videos that the owner made. It is not offered to anyone else.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool uses

The tool signs in only to the owner's own Google account through OAuth 2.0. With that access it:

  • uploads videos to the owner's channel and sets their title, description, tags and publish time
  • sets the thumbnail of those videos
  • posts comments on the owner's own videos

It does not read, collect, store or share any data about other users or other channels.

Storage and deletion

The OAuth token is saved only on the owner's computer. No data is sent to any server other than Google's. There is no database and no analytics. Deleting the token file removes all stored authorization data.

Revoking access

Access can be revoked at any time from Google security settings.
